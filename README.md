# 🚲 Softbyke

**Site de venda de bicicletas**

## 📌 Sobre o projeto

O Softbyke é um site de venda de bicicletas desenvolvido como projeto acadêmico, com o objetivo de praticar os conhecimentos adquiridos durante as aulas de desenvolvimento web.

O projeto aplica conceitos de estruturação de páginas, estilização e interatividade, utilizando tecnologias fundamentais do desenvolvimento front-end.

## ✨ Funcionalidades

- Apresentação de um site voltado à venda de bicicletas.
- Organização visual dos conteúdos e das páginas.
- Aplicação de estilos para compor a interface do site.
- Uso de JavaScript para praticar os conceitos estudados em aula.

## 🔄 Desenvolvimento do projeto

O desenvolvimento foi realizado durante as aulas, seguindo as instruções e atividades propostas pelo professor.

O projeto teve como foco a aplicação prática dos fundamentos de desenvolvimento web e a construção de uma interface para um site comercial.

## 🎨 Protótipo e interface

O projeto possui uma interface desenvolvida para apresentar a proposta de uma loja de bicicletas.

*Imagens do site serão adicionadas posteriormente.*

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação das páginas.
- **CSS3** — estilização e layout.
- **JavaScript** — interatividade e aplicação dos conceitos estudados.

## 🎓 Contexto acadêmico

Projeto desenvolvido para fins educacionais, como parte das atividades práticas das aulas de desenvolvimento web.
