# 🚲 Softbyke

**Site de venda de bicicletas**

## 📌 Sobre o projeto

O Softbyke é um site de venda de bicicletas desenvolvido como projeto acadêmico, com o objetivo de colocar em prática os conhecimentos adquiridos durante as aulas de desenvolvimento web.

## ✨ Funcionalidades

- Apresentação de um site voltado à venda de bicicletas.
- Organização dos conteúdos e elementos da página.
- Estilização da interface do site.
- Aplicação dos conceitos de JavaScript estudados em aula.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎓 Contexto acadêmico

Projeto desenvolvido para fins educacionais, seguindo as instruções e atividades propostas pelo professor durante as aulas.
